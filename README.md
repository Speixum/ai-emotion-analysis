AI 情绪分析系统：DeepFace 与通义千问的融合
AI 情绪识别与分析系统
基于 DeepFace 表情识别和通义千问大模型的实时多模态情绪分析系统，支持摄像头实时检测、大语言模型智能分析、异步语音预警、情绪统计可视化等完整功能。

🛠️ 技术栈
- 计算机视觉：OpenCV + DeepFace

🚀 快速开始
1. 环境要求
- Python 3.8 ~ 3.11（推荐 3.10，兼容性最好）
- Windows 10/11（Linux/MacOS 需调整语音引擎）
- 可用的摄像头设备
2. 安装依赖
# 克隆仓库
git clone https://github.com/Speixum/ai-emotion-analysis.git
cd ai-emotion-analysis

# 安装所有依赖包
pip install -r requirements.txt
3. 配置 API 密钥
1. 前往阿里云通义千问控制台获取免费 API 密钥
2. 打开 qwen_api.py 文件，修改第 12 行：
# 将此处替换为你的API密钥
self.api_key = "你的通义千问API_KEY"
4. 运行程序
python main.py

---
📖 使用说明
1. 点击开启检测按钮启动摄像头和情绪识别
2. 系统会实时显示当前情绪、AI 分析结果和情绪占比图表
3. 当检测到长时间情绪异常时，会自动发出语音预警
4. 点击保存记录可将所有检测数据导出为 CSV 文件
5. 点击重置统计可清空所有历史数据，重新开始检测

🎯 系统特点
1. 多模态融合：将计算机视觉的情绪检测能力与大语言模型的自然语言理解能力相结合
2. 实时性优化：模型预加载 + 线程池异步处理，单帧检测耗时 < 50ms，帧率稳定在 25FPS 以上
3. 用户友好：简洁直观的图形界面，无需复杂配置，开箱即用
4. 健壮性强：全面的异常处理机制，程序不会因摄像头断开、网络异常等问题崩溃
5. 可扩展性：模块化设计，易于添加新的情绪类型、预警规则和分析功能
